\# MindGuard AI 🧠

\### AI-Powered Teen Emotional Risk Detection System



\## Overview

MindGuard AI analyzes teen mood patterns, provides personalized coping tips, 

and tracks emotional trends over time — helping young people better understand 

and manage their mental health.



Built in 36 hours at NorCal Hacks 2026, the largest high school hackathon 

in Northern California.



\## Built With

\- Python

\- Hugging Face Transformers

\- Streamlit

\- Pandas

\- Matplotlib

\- fpdf



\## Features

\- Mood analysis using NLP

\- Personalized coping tip generation

\- Emotional trend tracking over time

\- PDF report export
